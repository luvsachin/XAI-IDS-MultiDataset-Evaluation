# Dataset Instructions

The repository does not redistribute raw or processed benchmark datasets.

The experiments use:

1. NSL-KDD
   - Official source: https://www.unb.ca/cic/datasets/nsl.html

2. UNSW-NB15
   - Official source: https://research.unsw.edu.au/projects/unsw-nb15-dataset

3. CICIDS2017
   - Official source: https://www.unb.ca/cic/datasets/ids-2017.html

Place downloaded raw datasets under:

- `02_Data/raw/NSL-KDD/`
- `02_Data/raw/UNSW-NB15/`
- `02_Data/raw/CICIDS2017/`

Processed matrices are generated locally by the scripts in `03_Code/scripts/`.
Raw and processed datasets are excluded from version control because of size,
licensing, and redistribution constraints.
